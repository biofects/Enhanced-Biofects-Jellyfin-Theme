# Security Policy

## Supported Versions

Only the latest revision on the `main` branch is actively supported. Update to
the newest stylesheet and reproduce the issue with Jellyfin's default theme
before reporting it.

## Reporting a Vulnerability

Do not open a public issue for a suspected vulnerability.

Use [GitHub private vulnerability reporting](https://github.com/biofects/Enhanced-Biofects-Jellyfin-Theme/security/advisories/new) and include:

- A description of the issue and its potential impact
- The affected Jellyfin and web-client versions
- Reproduction steps or a minimal proof of concept
- Any known mitigations

You should receive an acknowledgement within 72 hours. Please allow reasonable
time for investigation and a fix before public disclosure.

For visual defects, compatibility problems, and other non-sensitive bugs, use
the repository's public bug-report template instead.
